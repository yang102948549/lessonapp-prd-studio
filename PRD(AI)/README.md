# PRD(AI) — 대화형 수업 웹앱 PRD 도우미

루트 질문 폼 사이트와 같은 질문 순서를 AI(Gemini)가 대화로 이끄는 버전입니다. 차이점은 AI가 교사의 수업을 이해하고 판단해, 방금 한 말에 맞춘 **추천 답변 칩**과 **PRD 초안 갱신**을 돌려준다는 점입니다.

## 흐름

1. **AI 호출 없이(키 불필요)**: 학교급 → 학년 → 성취기준 → "이 성취기준으로 어떤 수업을 하고 싶으세요?". 선택지는 질문 바로 아래에 나오고, 고르면 입력란에 채워집니다(성취기준은 체크를 풀면 사라짐). 고쳐서 전송합니다. 과목은 고른 성취기준의 교과로 채워집니다.
2. **수업의 기본 방향을 보내면 AI가 시작**: 계획 지도 순서(수업 단계 → 배움의 목표 → 앱의 형태 → 활동 설계 → …)대로 비어 있는 첫 항목을 하나씩 묻습니다. 교사가 먼저 말한 내용은 해당 칸에 기록하고 순서는 지킵니다.
3. 앱의 형태를 물을 차례에는 형태 선택지(퀴즈·방탈출·시뮬레이션 등)가 질문 아래에 나타나고, 누르면 입력란에 줄이 들어갑니다. 그 밖의 선택지는 AI가 만든 맞춤 칩입니다.

## 사용

- 실행: 상위 폴더에서 `python -m http.server 4173` 후 `http://127.0.0.1:4173/PRD(AI)/`
- 설정 탭에서 Gemini API 키를 연결합니다(키는 메모리에만 유지). 모델은 Gemini 3 계열에 생각 수준 `minimal`로 호출합니다.
- AI 역할 지침은 `prompt.js`, 질문 단계와 PRD 섹션은 상위 폴더의 `planning.js`(루트 사이트와 공유)에서 고칩니다.
- 오른쪽 기획서는 대화에 따라 항목별로 채워지고 직접 고칠 수 있습니다. 기획서가 곧 최종 PRD이므로 별도의 상세 PRD 생성은 없습니다. 복사 또는 MD 다운로드로 개발 AI에 전달합니다.
