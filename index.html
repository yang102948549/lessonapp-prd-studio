Google AI Studio에서 키 발급받기 ↗
  1. Google 계정으로 로그인하고 필요한 약관에 동의하세요.
  2. API Keys에서 API 키 만들기(Create API key)를 선택하세요. 이미 생성된 키가 있으면 사용할 수 있어요.
  3. 프로젝트를 선택하거나 새로 만든 뒤 키를 복사하세요.
  4. 위 입력란에 붙여넣고 연결 확인을 누르세요.

프로젝트가 보이지 않으면 AI Studio의 Projects에서 가져오세요. 학교 계정은 관리자 권한에 따라 발급이 제한될 수 있어요.
