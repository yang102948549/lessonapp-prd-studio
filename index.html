저장 정보

프로젝트는 지금 사용하는 이 브라우저(이 기기)에만 저장돼요. 서버로 보내지 않고 다른 사람과 공유되지도 않아요. 최대 20개까지 저장할 수 있어요.

자료가 사라지는 경우

  • 브라우저에서 사이트 데이터·쿠키·인터넷 사용 기록을 삭제했을 때
  • 시크릿(비공개) 창에서 사용하고 창을 닫았을 때
  • 다른 브라우저나 다른 기기에서 접속했을 때(서로 보이지 않아요)
  • Safari 등 일부 브라우저가 오래 쓰지 않은 사이트 데이터를 자동 정리할 때(약 7일)
  • 내가 프로젝트를 직접 삭제했을 때

정해진 보관 기간은 없어요. 중요한 프로젝트는 아래 내보내기로 파일에 보관해 두세요.

프로젝트 백업프로젝트는 이 브라우저에만 저장돼요. 파일로 내보내 두면 다른 기기나 브라우저에서 불러올 수 있어요.

무료 사용량 도움말

상세 PRD 생성은 AI를 4번(2번씩 동시에) 호출하고, 코치 질문·AI 제안은 1번, 완성 후 수정 요청은 1번 호출해요. 무료 등급은 분당·하루 호출 수가 제한되니 연결 후 모델 목록에서 가벼운 Flash 계열(Flash-Lite 등)을 고르면 한도에 여유가 생겨요. 한도는 Google이 바꿀 수 있어요.

연결이 확인되면 이 키로 사용할 수 있는 모델이 목록에 나타납니다.

API 키가 처음이신가요?

Google AI Studio에서 키 발급받기 ↗
  1. Google 계정으로 로그인하고 필요한 약관에 동의하세요.
  2. API Keys에서 API 키 만들기(Create API key)를 선택하세요. 이미 생성된 키가 있으면 사용할 수 있어요.
  3. 프로젝트를 선택하거나 새로 만든 뒤 키를 복사하세요.
  4. 위 입력란에 붙여넣고 연결 확인을 누르세요.

프로젝트가 보이지 않으면 AI Studio의 Projects에서 가져오세요. 학교 계정은 관리자 권한에 따라 발급이 제한될 수 있어요.
